# Chorus

**Your agent in Ableton Live, Logic Pro and FL Studio.**

Chorus reads the session open in your DAW, proposes changes as a diff on the piano roll (notes, mix moves, plug-in settings, arrangements), and applies them only when you say so, with undo for everything it does.

## Download

Get the latest version from [Releases](https://github.com/trychorus/chorus/releases/latest), or from [askchorus.io](https://askchorus.io/download/).

- macOS 12 or later, Apple silicon
- Ableton Live 12, Logic Pro 12, or FL Studio 2025 or later
- Your own Anthropic API key ([console.anthropic.com](https://console.anthropic.com/settings/keys))

Chorus is signed with a Developer ID and notarized by Apple. On first launch it walks you through connecting your DAW and adding your key.

## Help

Docs and setup steps for each DAW: [askchorus.io/docs](https://askchorus.io/docs/)
